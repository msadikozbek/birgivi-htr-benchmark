# Yazma Eser Görseli

Çalışmanın örneklemi: İmam Birgivî'nin *el-Ehâdîsü'l-Erbaûn* (Kırk Hadis)
risalesinin ilk sayfası; Osmanlı nesih hattı, kırmızı mürekkep ve satır arası
tashihler içeren nüsha.

**Telif uyarısı:** Görselin yeniden yayım hakkı ilgili kütüphaneye/koleksiyona
aittir. Görsel dosyası ancak izin alındığında bu klasöre eklenmelidir.

Eklenmesi gereken künye bilgileri:
- Kütüphane / koleksiyon adı:
- Demirbaş / arşiv numarası:
- Varak / sayfa:
- Erişim bağlantısı (varsa):
- İzin durumu:
